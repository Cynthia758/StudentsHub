# StudentHub Portal

## Project Overview
StudentHub is a responsive web portal designed to provide students with easy access to college information and services.

## Features
- Home Page
- About Page
- Student Registration
- Login
- Dashboard
- Events
- Profile
- FAQ
- Contact
- Admin Panel

## Technologies Used

- CSS3
- JavaScript
